# CodeTester 🌑

**Autonomous AI QA Mission Control**

CodeTester is a high-end, experimental QA platform that transforms natural language intent into autonomous browser testing, realistic bug evidence, and CI-aware release gates.

## 🌌 The Abyssal Overgrowth Interface
This project features the **Abyssal Overgrowth** design system—a cinematic fusion of deep void aesthetics, bioluminescent nature, and smoldering industrial UI.

- **Neural Interface Terminal**: Real-time simulation of AI QA reasoning.
*   **Asymmetrical Workflow**: A scroll-reactive root system visualizing the QA lifecycle.
- **Thermal Metrics**: Monolithic obsidian pricing tiers with reactive magma lighting.
*   **Cinematic Background**: Multi-layered parallax space parallax with drifting embers and film grain.

## 🚀 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Oswald & Space Grotesk

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:4173](http://localhost:4173) with your browser to see the result.

## 🏗️ Architecture
- `/app`: Next.js App Router and global styles.
- `/components/abyssal`: Atmospheric theme components.
- `/components/landing`: Core landing page sections.
- `/components/motion`: Interactive motion utilities.
- `/lib`: Shared data and utility functions.
